# 🛡️ CyberSathi AI
### AI-Powered Cyber Fraud Prevention & Response Platform

CyberSathi AI is an intelligent cybersecurity platform designed to help users identify, prevent, and respond to cyber frauds in real time. The platform leverages Artificial Intelligence to detect suspicious activities, educate users about online threats, and provide instant guidance during cyber emergencies.

---

## 🚀 Features

### 🤖 AI Fraud Detection
- Detects suspicious transactions and online scams.
- AI-based fraud risk analysis.
- Real-time fraud alerts.

### 💬 AI Chat Assistant
- Answers cybersecurity-related questions.
- Provides instant guidance on fraud prevention.
- Available 24/7.

### 🚨 Emergency SOS
- One-click emergency reporting.
- Quick access to cyber crime helpline.
- Share live location during emergencies.

### 🛡️ Scam Detection
- Detect phishing websites.
- Identify fake UPI payment screenshots.
- Check suspicious links and QR codes.

### 📍 Nearby Police Assistance
- Locate nearby cyber police stations.
- Navigation using Google Maps.
- Emergency contact information.

### 📚 Cyber Awareness
- Latest cyber fraud news.
- Security tips and best practices.
- Interactive awareness quizzes.

### 👤 User Dashboard
- Fraud report history.
- Saved reports.
- Profile management.

### 📊 Admin Dashboard
- Manage users.
- View fraud reports.
- Analytics and statistics.
- AI monitoring.

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/CyberSathi-AI.git
```

Go to project folder

```bash
cd CyberSathi-AI
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
